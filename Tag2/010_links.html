Anchor-Tags (<a>) - Links in HTML

Mit dem Anchor-Tags können wir Links erstellen. Links führen zu anderen Seiten, Dateien oder zu einer Stelle auf der selben Seite.

1. Grundaufbau eines Links

So sieht ein einfacher Link im Code aus:

                    <a href="https://example.com">Ich bin ein Link</a>

So sieht der Link im Browser aus:

Ich bin ein Link

2. Das Attribut href

href steht für Hypertext Reference.
Das Attribut href gibt an, wohin der Link führt. Ohne href ist es kein richtiger Link.

  • href="010_links.html" → Link zu einer Datei im gleichen Ordner
  • href="#ziel" → Link zu einer Stelle auf derselben Seite
  • href="https://example.com" → Link der zu einer anderen Webseite führt

3. Link in einem neuen Tab öffnen

Mit target="_blank" öffnet sich der Link in einem neuen Tab:

                    <a href="https://example.com" target="_blank" rel="noopener noreferrer">Öffnet in einem neuen Tab</a>

So sieht der Link im Browser aus:

Öffnet ein neues Tab
noopener
Sicherheit bei target="_blank", das die Zielseite, meine Seite nicht manipulieren kann.
noreferrer
Datenschutz, bedeutet das die Zielseite nicht sieht, woher bzw. von welcher Seite der Klick kam.
nofollow
Für Suchmaschinen und sagt: "Ich empfehle diese Seite nicht weiter!".
rel
eng. relationship / dt. Beziehung

4. E-Mail und Telefon Links

E-Mail (mailto)

                        <a href="mailto:beispiel@gmail.com">E-Mail schreiben</a>

Unser Browser öffnet das Standard E-Mail-Programm des Nutzers. Und erstellt automatisch: Empfänger (E-Mail schon ausgefüllt), Betreff: leer, Text: leer.

E-Mail schreiben E-Mail schreiben

Telefon (tel)

                        <a href="tel:+49123456789">Jetzt anrufen</a>

Smartphones und Tablets öffnen direkt die Telfon App zum Anrufen. PCs können die Funktion nur nutzen, wenn die dafür zuständigen Apps vorhanden sind.

Jetzt anrufen

5. Interne Links (Sprungmarken)

Du kannst innerhalb derselben Seite springen. Dafür braucht das Ziel-Element eine id.

                    <a href="#ziel">Spring zum Ziel</a>
Spring zum Ziel

Bei Seiten auf bestimmten Sprungmarken landen

Du kannst direkt auf eine bestimmte Seite springen, wenn du eine Stelle angegeben hast und diese eine entsprechende id besitzt.

                    <a href="/Tag1/040_listen.html#rucksack">Landet auf der Seite mit der Sprungmarke Rucksack</a>
