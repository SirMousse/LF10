Kontaktformulare in HTML

Formulare helfen uns dabei, Daten von Nutzern einzusammeln.
Die wichtigsten Bausteine sind:

  • <form> = der Formular Rahmen (Container)
  • <label> = Beschriftung für ein Eingabefeld
  • <input> = Eingabefeld (Bsp.: E-Mail, Namen, Telefonnummer, Passwort etc.)
  • <textarea> = größeres Textfeld (bsp.: Kommentar oder Nachricht)
  • <select> und <option> = Dropdown Auswahl
  • <button> = Button (Absenden/Zurücksetzen)

1. Das einfache Kontaktformular

Ein Kontaktformular besteht meistens aus Name, E-Mail und Nachricht.

2. Wichtige Form-Attribute: action und method

action=""
Wohin die Daten geschickt werden (Bsp.: eine Server Adresse oder ein Skript.)

method="GET"
Daten werden in die URL geschrieben (gut für eine Suche, schlecht für unsere sensiblen Daten).

method="POST"
Daten werden im Hintergrund gesendet (in einem Request Body → Standard Formular)

HINWEIS: Ohne echten Server passiert beim absenden oft nichts Sichtbares, aber HTML "baut" das Formular korrekt.

3. Input-Typen und ihre Funktionen

Der type sagt dem Browser, welche Art von Daten erwartet werden. Dadurch bekommt man die passenden Tastaturen am Handy/Tablet und machnmal auch eine automatische Überprüfung.

placeholder=""
Ein Hinweistext im Feld (verschwindet beim Tippen).
min/ max
min = minimum und max = maximum und eine Grenze der Zahlen( oder eines Datums).

4. Pflichtfelder und einfache Validierung

Mit required kann man Felder verpflichtend setzen. Der Browser verhindert dann das Absenden, wenn etwas fehlt.

5. Auswahlfelder: select, radio und checkbox

Kontaktwunsch:


selected
diese Option wird von Anfang an angezeigt
disabled
Option kann später nicht erneut ausgewählt werden
value=""
Option hat keinen eigentlichen Wert
radio
Nur eine Option ausgewählt wird (name muss in allen Input Versionen der selbe sein).
select
Ist eine Auswahlliste zum Aufklappen.
checkbox
Ist flexible zwischen an und aus bzw. mehreren Auswahlmöglichkeiten.

6. Buttons: submit, reset, button


type="submit"
Sendet das Formular ab.

type="reset"
Setzt alle Felder auf den Startzustand zurück.

type="button"
Macht erst etwas, wenn JavaScript hinzugefügt wurde.
