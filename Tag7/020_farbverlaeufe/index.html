CSS Farbverläufe (Gradients)

Mit CSS kannst du Farbverläufe als Hintergrund verwenden. Farbverläufe sind keine Bilder, sondern werden direkt von CSS erzeugt.

Die wichtigsten Farbverläufe:

  1. Linear Gradient = Verlauf in eine Richtung
  2. Radial Gradient = Verlauf von der Mitte nach außen
  3. Conic Gradient = kreisförmiger Verlauf

1. Linear Gradient linear-gradient

Ein linearer Verlauf, geht in eine Richtung (z.B. von oben nach unten).

linear-gradient (oben nach unten) 
                    .linear-basic{
                        background: linear-gradient(#00a8ff, crimson);
                    }

Du kannst auch eine Richtung angeben:

linear-gradient (nach links) 
                    .linear-direction{
                        background: linear-gradient(to left, #6465a5, #f05837);
                    }

Wir können auch einen Winkel benutzen:

linear-gradient(420deg) 
                    .linear-angle{
                        background: linear-gradient(45deg, #00743f, #f2a104);
                    }

2. Radial Gradient (radial-gradient)

Der Farbverlauf geht von der Mitte nach außen (kreisförmig)

radial-gradient 
                    .radial-basic{
                        background: radial-gradient(circle, #c0334d, #f1931b);
                    }

Du kannst die Form beeinflussen:

radial-gradient(ellipse) 
                    .radial-ellipse{
                        background: radial-gradient(ellipse, #212027, #f22f08);
                    }

3. Conic Gradient (conic-gradient)

Ein conic-gradient ist ein kreisförmiger Verlauf um einen Mittelpunkt. Er eignet sich gut für z.B. Diagramme und Deko.

conic-gradient 
                    .conic-basic{
                        background: conic-gradient(#003d73, #edd170, #1ecfd6, #c05640, #0878a4);
                    }

4. Mehrere Farben und Farbstopps

Du kannst mehr als nur zwei Farben benutzen und auch Prozentwerte(Stops) angeben:

Mehrere Farbstopps 
                    .linear-stops{
                        background: linear-gradient(to right,
                        #8a8604 0%,
                        #383140 50%,
                        #cac7d7 90%);
                    }

5. Typische Einsatzfälle:

  • Header Hintergrund
  • Karten/ Boxen
  • Buttons (dezent!)
  • Hintergründe bei Sektionen
