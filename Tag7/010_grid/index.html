CSS Grid - Grundlagen

2D Layout: Reihen(Rows) und Spalten(Columns) können einfach gebaut werden. Es ist unser Grundgerüst.

1. Grid einschalten

Grid wird auf dem Eltern Element aktiviert: display: grid. Die direkten Kinder, werden sogenannte "Grid-Items".

1
2
3
4
                .basic-grid{
                    display: grid;  -> Startet Grid
                }

2. Spalten definieren: grid-template-columns

Bestimmt, wie viele Spalten es gibt und wie breit sie sind.

                    display: grid;
                    grid-template-columns: 1fr 1fr 1fr;     -> 3 gleich große Spalten
                    gap: 8px;

                    gap: 8px;
                }

3. Reihe definieren: grid-template-rows

Bestimmt die Höhe jeder Reihe.

1
2
3
4
                .rows{
                    display: grid;
                    grid-template-columns: 1fr 1fr;
                    grid-template-rows: 60px 120px; -> Reihe 1 = 60px hoch | Reihe 2 = 120px hoch
                    gap: 8px;
                }

MERKE:
grid-template-columns bezieht sich auf die Breite und grid-template-rows bezieht sich auf die Höhe!!!

4. Abstände in Grid: gap

Mit gap bekommen wir Abstände zwischen den Zeilen.

1
2
3
4
                .grid-gap{
                    display: grid;
                    grid-template-columns: repeat(2, 1fr); ->repeat(x, yfr) = x gibt an wie viele Spalten es geben soll 
                                                                            | y gibt an wie groß die Spalten sein sollen
                    gap: 8px;
                }

5. Items plazieren: grid-column und grid-row

Wir können einzelne Elemente über mehrere Spalten bzw. Reihen ziehen.

Spannt zwei Spalten
2
3
Spannt zwei Reihen

7
                .place-grid{
                    display: grid;
                    grid-template-columns: repeat(3, 1fr);
                    gap: 8px;
                }

                .span-2{
                    grid-column: span 2;        -> gibt die Spanne an für die Breite
                    background-color: tomato;
                }

                .tall{
                    grid-row: span 2;           -> gibt die Spanne an für die Höhe
                    background-color: aquamarine;
                }
