CSS einbinden - Inline, Intern und Extern

Es gibt drei Arten, CSS in HTML einzubinden:

  1. Inline CSS = direkt im HTML Element
  2. Interne CSS = im <style>-Tag im head
  3. Extrene CSS = in einer extra .css Datei (verlinkt im head)

1. Inline CSS

Inline CSS wird direkt im HTML-Tag mit dem Attribute style geschrieben.

Beispiel:

Dieser Text ist mit Inline CSS gestylte. 

                    <p style="color: red;              -> Farbe der Schrift
                              background: #ffeeee;     -> ist die Hintergrundfarbe
                              padding: 8px;"           -> padding ist der Innenabstand (Platz zw. dem Inhalt eines Elements und seinem Rand)
                    >
                        Dieser Text ist mit Inline CSS gestylte.
                    </p>

Wann ist das sinnvoll? Fast nie. Nur für schnelle Tests oder einzele Ausnahmen.
Warum ist es schlecht? Unübersichtlich, schlecht wartbar.

2. Interne CSS (im <style>-Tag)

Internes CSS steht im <style>-Tag der HTML Datei. Es gilt für die gesamte Seite.

Beispiel:

Dieser Bereich ist mit interem CSS gestylt. 

                    <style>
                    body{
                        font-family: Arial, Helvetica, sans-serif;  -> Schriftart/Schriftfamilie wird ausgewählt
                        line-height: 1.5;                           -> Zeilenabstand zueinander
                    }

                    .box{
                        border: 2px solid black;    -> border ist der Rahmen = 2px ist die stärke des Rahmens/ solid ist fester Rahmen / black ist die Farbe des Rahmens
                        padding: 10px;              -> = Innenabstand
                        margin: 10px 0;             -> margin = Außenabstand (oben, rechts, unten, links = Größenangaben) | 10px oben + unten / 0 rechts + links
                    }

                    .intern{
                        color: darkgreen;       -> = Farbe der Schrift
                        background: #e6ffe6;    -> = Hintergrundfarbe
                        padding: 8px;           -> = Innenabstand
                    }

Wann ist es sinnvoll? Bei kleinen Projekten und Übungen.
Warum? Alles in einer Datei leichter verstehen kann.

3. Externe CSS (seperate Datei)

Externe CSS liegt in einer eigenen Datei (z.B. style.css) und wird mit <link> eingebunden.

Beispiel:

Dieser Bereich ist mit externem CSS gestylt. 

                    /* style.css */
                    .extern{
                        color: white;           -> Schriftfarbe
                        background: #3333cc;    -> Hntergrundfarbe
                        padding: 10px;          -> Innenabstand
                    }

Wann ist es sinnvoll? Fast immer bei "echten" Webseiten.
Warum? Sauber, wiederverwendbar und leicht wartbar.

4. Priorität und Reihenfolge

Wenn mehrere Styles auf das selbe Element wirken, gilt:

  1. Inline CSS (höchste Priorität)
  2. Interne CSS
  3. Externe CSS (niedrigste Priorität)
