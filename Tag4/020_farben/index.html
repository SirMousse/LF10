Farben in CSS - Grundlagen

In CSS können wir Farben auf verschiedene Arten angeben. Farben werden z.B.: für Texte, Hintergrundfarben und Rahmen verwendet.

  1. Farbennamen (z.B.: red, green)
  2. HEX-Werte (z.B.: #ff0000)
  3. RGB/ RGBA (z.B.: rgb(255, 0, 0))
  4. HSL/ HSLA (z.B.: hsl(0, 100%, 50%))

1. Farbnamen

CSS kennt viele eingebaute Farbnamen wie red, blue und green.

Ich bin rot (red).

Ich bin blau (blue).

Ich bin grün (green).

                    .name-red{
                        color: red;
                    }

                    .name-blue{
                        color: blue;
                    }

                    .name-green{
                        color: green;
                    }

Einfach, aber begrenzte Auswahl und oft nicht exakt der gewünschte Farbton.

2. HEX-Farben (#RRGGBB)

Hex-Farben sind sehr verbreitet im Web. Sie bestehen aus #RRGGBB (Rot, Grün, Blau). Die Werte im Hexadezimal gehen von 00 bis FF, dabei steht 00 = 0 (nichts) und FF = 255 (volle Stärke).

FF wird berechnet 15 x 16 + 15 = 255. 15 -> steht für 1 bis F(15) 16 -> steht für alle Hexadezimalwerte (0 bis F) + 15 wird dazugrechnet, da man die 0 Ausgelassen hat bei dem ersten Wert.

Ich bin #ff0000 (ROT).

Ich bin #0000ff (BLAU).

Ich bin #008000 (GRÜN).

                    .hex-red{
                        color: #ff0000;
                    }

                    .hex-blue{
                        color: #0000ff;
                    }

                    .hex-green{
                        color: #008000;
                    }

Hex-Farben sind sehr genau und Standard Design in der Webentwicklung.

3. RGB und RGBA

RGB mischt Rot, Grün und Blau (0-255).
RGBA hat zusätzlich einen Alpha-Wert (Transparent 0 bis 1).

Ich bin rgb(255, 0, 0)

Ich bin rgba(255, 0, 0, 0.4)

Ich bin rgb(0, 128, 0)

Ich bin rgba(0, 128, 0, 0.6)

Ich bin rgb(0, 0, 255)

Ich bin rgba(0, 0, 255, 0.8)

Super für Transparenz (Overlays/ Effekte).

4. HSL und HSLA

HSL steht für: Farbton (Hue), Sättigung (Saturation) und Helligkeit (Lightness).

  1. Welche Farbe?
  2. Wie kräftig?
  3. Wie hell?

Ich bin hsl(0, 100%, 50%)

Ich bin hsla(0, 100%, 50%, 0.8)

Ich bin hsl(120, 100%, 25%)

Ich bin hsla(120, 100%, 25%, 0.6)

Ich bin hsl(220, 80%, 50%)

Ich bin hsla(220, 80%, 50%, 0.4)

Sehr intuitiv für Design (heller/ dunkler stellen oder Farbton drehen).
