============================================================
           CSS-ÜBUNG: DIE ABENTEURER-GILDE
============================================================

Dauer: ungefähr 40 Minuten

Situation:

Du wurdest als neuer Schreiber der Abenteurer-Gilde eingestellt.

Eigentlich solltest du nur Quests eintragen.

Leider hat der Gildenmeister herausgefunden,
dass du "irgendwas mit Computern" machst.

Jetzt sollst du die Webseite der Gilde verschönern.

Die aktuelle Webseite sieht ungefähr so aus,
als hätte ein Goblin sie mit Notepad geschrieben.

Deine Aufgabe:

Mach die Gilden-Webseite mit CSS schöner.

Heute brauchst du:

- externes CSS
- internes CSS
- Inline CSS
- color
- background
- padding
- margin
- border

Am Ende lernst du noch genau EINE neue CSS-Eigenschaft.

Keine Sorge.

Der Drache kommt erst später.


============================================================
AUFGABE 1: DATEIEN VORBEREITEN
============================================================

Erstelle einen Ordner:

abenteurer-gilde


Darin brauchst du:

index.html

style.css


Erstelle in index.html ein normales HTML-Grundgerüst.

Du brauchst also unter anderem:

<!DOCTYPE html>

<html>

<head>

<body>


Gib der Webseite außerdem den Titel:

Abenteurer-Gilde


============================================================
AUFGABE 2: EXTERNES CSS EINBINDEN
============================================================

Verbinde deine HTML-Datei mit:

style.css


Die CSS-Datei soll im <head> eingebunden werden.


TIPP:

Dafür gibt es das Element:

<link>


Versuche zuerst selbst herauszufinden,
wie die vollständige Zeile aussehen muss.

============================================================
AUFGABE 6: EXTERNES CSS
============================================================

Öffne jetzt:

style.css


Style dort zuerst den body.


Benutze:

font-family: Arial, Helvetica, sans-serif;

line-height: 1.5;


Danach kümmern wir uns um:

.quest


Jede Quest soll einen Rahmen bekommen:

border: 2px solid black;


Außerdem soll jede Quest bekommen:

padding: 10px;

margin: 10px 0;


Speichern.

Webseite anschauen.


============================================================
KURZE DENKPAUSE
============================================================

Schau dir deine Quest-Boxen an.


Was macht:

border?


Was macht:

padding?


Was macht:

margin?


Versuche es mit eigenen Worten zu erklären.


TIPP:


padding

ist der Abstand INNERHALB eines Elements.


margin

ist der Abstand AUSSERHALB eines Elements.


============================================================
AUFGABE 7: KLEINES EXPERIMENT
============================================================

Ändere bei .quest kurz:

padding: 10px;

zu:

padding: 40px;


Was verändert sich?


Danach wieder zurück auf:

padding: 10px;


Jetzt ändere:

margin: 10px 0;

zu:

margin: 40px 0;


Was verändert sich diesmal?


Danach wieder zurück auf:

margin: 10px 0;


FRAGE:

Kannst du jetzt den Unterschied zwischen
padding und margin erklären?

AUFGABE 10: INLINE CSS
============================================================

Jetzt brauchen wir noch Inline CSS.


Erstelle einen neuen Absatz:

Wichtig:

DENKFRAGE
============================================================

Du hast jetzt drei Arten von CSS benutzt.


1. Wo steht EXTERNES CSS?

============================================================
AUFGABE 11: DER CSS-KAMPF
============================================================

Erstelle einen neuen Absatz:


<p class="test">
Welche Farbe bekomme ich?
</p>


Schreibe in deine EXTERNE style.css:


.test {
    color: blue;
}


Speichern.

Welche Farbe hat der Text?


____________________________


Jetzt schreibst du in dein INTERNES CSS:


.test {
    color: green;
}


Speichern.


Welche Farbe hat der Text jetzt?


____________________________


Zum Schluss bekommt der Absatz Inline CSS:


style="color: purple;"


Welche Farbe hat der Text jetzt?


____________________________


Was fällt dir auf?


Für diese Übung kannst du dir merken:


Inline CSS

hat normalerweise eine sehr hohe Priorität.


Wenn zwei gleich starke Regeln vorhanden sind,
kann auch die Reihenfolge wichtig sein.


Das Thema dahinter heißt:

CSS Cascade


Das schauen wir uns später genauer an.

Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig
auf dasselbe Element wirken.


============================================================
AUFGABE 12: EINE NEUE SACHE
============================================================

Jetzt lernst du genau EINE neue CSS-Eigenschaft.


border-radius


Füge bei:

.quest

folgende Zeile hinzu:


border-radius: 10px;


Speichern und anschauen.


Was hat sich verändert?


____________________________


Teste danach kurz:

border-radius: 30px;


Was passiert?


____________________________


Stelle danach einen Wert ein,
der dir gefällt.


MERKE:

border-radius

macht die Ecken eines Elements rund.
