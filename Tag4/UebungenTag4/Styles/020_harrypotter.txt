============================================================ AUFGABE 6:
EXTERNES CSS
============================================================

Öffne jetzt:

style.css

Style dort zuerst den body.

Benutze:

font-family: Arial, Helvetica, sans-serif; line-height: 1.5;

Danach kümmern wir uns um:

.fach

Jedes Fach soll einen Rahmen bekommen:

border: 2px solid black;

Außerdem soll jedes Fach bekommen:

padding: 10px; margin: 10px 0;

Speichern.

Webseite anschauen.

padding

============================================================ AUFGABE 11:
DER CSS-ZAUBERKAMPF
============================================================

Erstelle einen neuen Absatz:

Welche Farbe bekomme ich?
Schreibe in deine EXTERNE style.css:

.test { color: blue; }

Speichern.

Welche Farbe hat der Text?

------------------------------------------------------------------------

Jetzt schreibst du in dein INTERNES CSS:

.test { color: green; }

Speichern.

Welche Farbe hat der Text jetzt?

------------------------------------------------------------------------

Zum Schluss bekommt der Absatz Inline CSS:

style=“color: purple;”

Welche Farbe hat der Text jetzt?

------------------------------------------------------------------------

Was fällt dir auf?

Für diese Übung kannst du dir merken:

Inline CSS

hat normalerweise eine sehr hohe Priorität.

Wenn zwei gleich starke Regeln vorhanden sind, kann auch die Reihenfolge
wichtig sein.

Das Thema dahinter heißt:

CSS Cascade

Das schauen wir uns später genauer an.

Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig auf dasselbe Element wirken.
