============================================================
              CSS-ÜBUNG: DETEKTIVBÜRO 404
============================================================

Dauer: ungefähr 40 Minuten

Situation:

Du arbeitest neu im Detektivbüro "404".

Eigentlich solltest du nur Akten sortieren.

Dann hat dein Chef gesehen,
dass du "irgendwas mit Webseiten" kannst.

Seitdem ist das dein Problem.

Die Webseite des Büros sieht nämlich aus,
als hätte ein Verdächtiger sie absichtlich sabotiert.

Deine Aufgabe:

Mach die Detektiv-Webseite mit CSS schöner.

Heute brauchst du:

- externes CSS
- internes CSS
- Inline CSS
- color
- background
- padding
- margin
- border

Am Ende lernst du noch genau EINE neue CSS-Eigenschaft.

Keine Sorge.

Du musst heute keinen Mordfall lösen.

Nur CSS.

Das ist manchmal ähnlich kompliziert.


============================================================
AUFGABE 1: DATEIEN VORBEREITEN
============================================================

Erstelle einen Ordner:

detektivbuero-css


Darin brauchst du:

index.html

style.css


Erstelle in index.html ein normales HTML-Grundgerüst.

Du brauchst also unter anderem:

<!DOCTYPE html>

<html>

<head>

<body>


Gib der Webseite außerdem den Titel:

Detektivbüro 404


============================================================
AUFGABE 2: EXTERNES CSS EINBINDEN
============================================================

Verbinde deine HTML-Datei mit:

style.css


Die CSS-Datei soll im <head> eingebunden werden.


TIPP:

Dafür gibt es das Element:

<link>


Versuche zuerst selbst herauszufinden,
wie die vollständige Zeile aussehen muss.


Falls nichts funktioniert:

1. Speichern.
2. Dateiname überprüfen.
3. Pfad überprüfen.
4. Browser aktualisieren.
5. Erst dann von Sabotage ausgehen.

AUFGABE 6: EXTERNES CSS
============================================================

Öffne jetzt:

style.css


Style dort zuerst den body.


Benutze:

font-family: Arial, Helvetica, sans-serif;

line-height: 1.5;


Danach kümmern wir uns um:

.fall


Jeder Fall soll einen Rahmen bekommen:

border: 2px solid black;


Außerdem soll jeder Fall bekommen:

padding: 10px;

margin: 10px 0;


Speichern.

Webseite anschauen.


============================================================
KURZE DENKPAUSE
============================================================

Schau dir deine Fall-Boxen an.


Was macht:

border?


Was macht:

padding?


Was macht:

margin?


Versuche es mit eigenen Worten zu erklären.


TIPP:


padding

ist der Abstand INNERHALB eines Elements.


margin

ist der Abstand AUSSERHALB eines Elements.


Stell dir eine Beweisbox vor:

Der Inhalt liegt innen.

padding ist der Platz zwischen dem Beweis
und dem Rand der Box.

margin ist der Abstand
zwischen dieser Box und der nächsten Box.

AUFGABE 11: DER CSS-FALL
============================================================

Jetzt untersuchen wir,
welche CSS-Regel gewinnt.


Erstelle einen neuen Absatz:


<p class="spur">
Welche Farbe bekomme ich?
</p>


Schreibe in deine EXTERNE style.css:


.spur {
    color: blue;
}


Speichern.


Welche Farbe hat der Text?


____________________________


Jetzt schreibst du in dein INTERNES CSS:


.spur {
    color: green;
}


Speichern.


Welche Farbe hat der Text jetzt?


____________________________


Zum Schluss bekommt der Absatz Inline CSS:


style="color: purple;"


Welche Farbe hat der Text jetzt?


____________________________


Was fällt dir auf?


Für diese Übung kannst du dir merken:


Inline CSS

hat normalerweise eine sehr hohe Priorität.


Wenn zwei gleich starke Regeln vorhanden sind,
kann auch die Reihenfolge wichtig sein.


Das Thema dahinter heißt:

CSS Cascade


Das schauen wir uns später genauer an.


Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig
auf dasselbe Element wirken.


Ein bisschen wie mehrere Zeugen.

Nur dass CSS manchmal widersprüchlicher ist.

Verdächtig freundlich.

BONUS FÜR SCHNELLE
============================================================

Nur wenn du früher fertig bist:


Erstelle eine neue Klasse:

.geheim


Sie soll:

- rote oder dunkle Schrift haben
- einen hellen Hintergrund haben
- einen Rahmen haben
- padding haben


Erstelle danach einen neuen Fall:


Name:

Akte X-404


Beschreibung:

In dieser Akte steht etwas sehr Geheimes.

Leider hat jemand
"sehr geheim"
mit Textmarker darüber geschrieben.


Gib diesem Fall:

class="fall"


UND zusätzlich die Klasse:

geheim


Versuche herauszufinden,
wie ein HTML-Element ZWEI Klassen bekommen kann.


TIPP:

Die Lösung sieht NICHT so aus:


class="fall"
class="geheim"


Ein Element braucht nur EIN class-Attribut.


Die beiden Klassen werden innerhalb
des class-Attributs eingetragen.
