============================================================
          CSS-ÜBUNG: MITTELERDE BRAUCHT CSS
============================================================

Dauer: ungefähr 40 Minuten

Situation:

Du bist neu in Mittelerde.

Eigentlich wolltest du nur gemütlich im Auenland sitzen,
etwas essen und möglichst keine Abenteuer erleben.

Leider hat Gandalf herausgefunden,
dass du "irgendwas mit Webseiten" kannst.

Jetzt sollst du die Webseite von Mittelerde verschönern.

Die aktuelle Webseite sieht ungefähr so aus,
als hätte ein Ork sie während seiner Mittagspause erstellt.

Deine Aufgabe:

Mach die Webseite mit CSS schöner.

Heute brauchst du:

- externes CSS
- internes CSS
- Inline CSS
- color
- background
- padding
- margin
- border

Am Ende lernst du noch genau EINE neue CSS-Eigenschaft.

Keine Sorge.

Du musst heute keinen Ring nach Mordor bringen.

============================================================

<body>

============================================================

Verbinde deine HTML-Datei mit:

wie die vollständige Zeile aussehen muss.

2. Dateinamen überprüfen.
3. Pfad überprüfen.
4. Browser aktualisieren.

AUFGABE 6: EXTERNES CSS
============================================================

Öffne jetzt:

style.css


Style dort zuerst den body.


Benutze:

font-family: Arial, Helvetica, sans-serif;

line-height: 1.5;


Danach kümmern wir uns um:

.gefaehrte


Jeder Gefährte soll einen Rahmen bekommen:

Außerdem soll jeder Gefährte bekommen:

margin: 10px 0;


Speichern.

Webseite anschauen.


============================================================
KURZE DENKPAUSE
============================================================

Schau dir deine Gefährten-Boxen an.


Was macht:

border?


Was macht:

padding?


Was macht:

margin?


Versuche es mit eigenen Worten zu erklären.


TIPP:


padding

ist der Abstand INNERHALB eines Elements.


margin

ist der Abstand AUSSERHALB eines Elements.


Stell dir eine Hobbit-Höhle vor:

Der Hobbit sitzt drinnen.

padding wäre der Platz zwischen dem Hobbit
und der Wand seiner Höhle.

margin wäre der Platz zwischen seiner Höhle
und der nächsten Hobbit-Höhle.

AUFGABE 11: DER CSS-KAMPF
============================================================

Jetzt kämpfen mehrere CSS-Regeln
um dasselbe Element.


Erstelle einen neuen Absatz:


<p class="ring">
Welche Farbe bekomme ich?
</p>


Schreibe in deine EXTERNE style.css:


.ring {
    color: blue;
}


Speichern.


Welche Farbe hat der Text?


____________________________


Jetzt schreibst du in dein INTERNES CSS:


.ring {
    color: green;
}


Speichern.


Welche Farbe hat der Text jetzt?


____________________________


Zum Schluss bekommt der Absatz Inline CSS:


style="color: purple;"


Welche Farbe hat der Text jetzt?


____________________________


Was fällt dir auf?


Für diese Übung kannst du dir merken:


Inline CSS

hat normalerweise eine sehr hohe Priorität.


Wenn zwei gleich starke Regeln vorhanden sind,
kann auch die Reihenfolge wichtig sein.


Das Thema dahinter heißt:

CSS Cascade


Das schauen wir uns später genauer an.


Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig
auf dasselbe Element wirken.


Der eine Ring mag sie alle knechten.

Bei CSS ist es leider etwas komplizierter.

des class-Attributs eingetragen.
