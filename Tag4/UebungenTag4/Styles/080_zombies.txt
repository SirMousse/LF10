============================================================
              CSS-ÜBUNG: ZOMBIE-APOKALYPSE
============================================================

Dauer: ungefähr 40 Minuten

Situation:

Die Zombie-Apokalypse ist ausgebrochen.

Eigentlich wolltest du heute nur in Ruhe programmieren.

Jetzt musst du zusätzlich:

- Vorräte zählen
- Türen verbarrikadieren
- Zombies vermeiden
- und eine Webseite für das Überlebenslager bauen

Warum die Webseite wichtig ist?

Niemand weiß es.

Aber der Chef sagt:

"Wir brauchen dringend besseres CSS."

Also gut.

Deine Aufgabe:

Mach die Webseite des Überlebenslagers mit CSS schöner.

Heute brauchst du:

- externes CSS
- internes CSS
- Inline CSS
- color
- background
- padding
- margin
- border

Am Ende lernst du noch genau EINE neue CSS-Eigenschaft.

Keine Sorge.

Die Zombies können laut aktuellem Stand noch kein CSS.

Das ist unser Vorteil.

============================================================

wie die vollständige Zeile aussehen muss.

3. Pfad überprüfen.

5. Nicht sofort die Zombies beschuldigen.

Sie können sehr viel.

Aber wahrscheinlich keine Pfade.

AUFGABE 6: EXTERNES CSS
============================================================

Öffne jetzt:

style.css


Style dort zuerst den body.


Benutze:

font-family: Arial, Helvetica, sans-serif;

line-height: 1.5;


Danach kümmern wir uns um:

.ueberlebender


Jeder Überlebende soll einen Rahmen bekommen:

border: 2px solid black;


Außerdem soll jeder Überlebende bekommen:

padding: 10px;

margin: 10px 0;


Speichern.

Webseite anschauen.


============================================================
KURZE DENKPAUSE
============================================================

Schau dir deine Boxen an.


Was macht:

border?


Was macht:

padding?


Was macht:

margin?


Versuche es mit eigenen Worten zu erklären.


TIPP:


padding

ist der Abstand INNERHALB eines Elements.


margin

ist der Abstand AUSSERHALB eines Elements.


Stell dir ein sicheres Lager vor:

Der Inhalt ist innen.

padding ist der Abstand
zwischen dem Inhalt und der Wand.

margin ist der Abstand
zwischen diesem Lager und dem nächsten Lager.

AUFGABE 11: DER CSS-KAMPF
============================================================

Jetzt testen wir,
welche CSS-Regel gewinnt.


Erstelle einen neuen Absatz:


<p class="test">
Welche Farbe bekomme ich?
</p>


Schreibe in deine EXTERNE style.css:


.test {
    color: blue;
}


Speichern.


Welche Farbe hat der Text?


____________________________


Jetzt schreibst du in dein INTERNES CSS:


.test {
    color: green;
}


Speichern.


Welche Farbe hat der Text jetzt?


____________________________


Zum Schluss bekommt der Absatz Inline CSS:


style="color: purple;"


Welche Farbe hat der Text jetzt?


____________________________


Was fällt dir auf?


Für diese Übung kannst du dir merken:


Inline CSS

hat normalerweise eine sehr hohe Priorität.


Wenn zwei gleich starke Regeln vorhanden sind,
kann auch die Reihenfolge wichtig sein.


Das Thema dahinter heißt:

CSS Cascade


Das schauen wir uns später genauer an.


Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig
auf dasselbe Element wirken.


Ein bisschen wie mehrere Zombies,
die gleichzeitig durch dieselbe Tür wollen.

Nur mit weniger Stöhnen
und mehr geschweiften Klammern.

Tor 3

wie ein HTML-Element ZWEI Klassen bekommen kann.

Ein Element braucht nur EIN class-Attribut.


Die beiden Klassen werden innerhalb
des class-Attributs eingetragen.
