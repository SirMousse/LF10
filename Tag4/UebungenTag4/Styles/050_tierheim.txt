============================================================
              CSS-ÜBUNG: TIERHEIM PFOTENGLÜCK
============================================================

Dauer: ungefähr 40 Minuten

Situation:

Du hilfst im Tierheim "Pfotenglück".

Eigentlich solltest du Hunde ausführen,
Katzen füttern
und möglichst nicht von einem Kaninchen beurteilt werden.

Dann hat jemand herausgefunden,
dass du "irgendwas mit Webseiten" kannst.

Seitdem sollst du die Tierheim-Webseite schöner machen.

Die aktuelle Seite funktioniert zwar,
sieht aber ungefähr so aus,
als hätte ein sehr motivierter Hamster sie gestaltet.

Deine Aufgabe:

Mach die Webseite mit CSS schöner.

Heute brauchst du:

- externes CSS
- internes CSS
- Inline CSS
- color
- background
- padding
- margin
- border

Am Ende lernst du noch genau EINE neue CSS-Eigenschaft.

Keine Sorge.

Du musst heute keine komplette Webseite bauen.

Die Tiere haben bereits genug Chaos organisiert.


============================================================
AUFGABE 1: DATEIEN VORBEREITEN
============================================================

Erstelle einen Ordner:

tierheim-css


Darin brauchst du:

index.html

style.css


Erstelle in index.html ein normales HTML-Grundgerüst.

Du brauchst also unter anderem:

<!DOCTYPE html>

<html>

<head>

<body>


Gib der Webseite außerdem den Titel:

Tierheim Pfotenglück


============================================================
AUFGABE 2: EXTERNES CSS EINBINDEN
============================================================

Verbinde deine HTML-Datei mit:

style.css


Die CSS-Datei soll im <head> eingebunden werden.


TIPP:

Dafür gibt es das Element:

<link>


Versuche zuerst selbst herauszufinden,
wie die vollständige Zeile aussehen muss.


Falls nichts funktioniert:

1. Speichern.
2. Dateinamen überprüfen.
3. Pfad überprüfen.
4. Browser aktualisieren.
5. Nicht sofort die Katze beschuldigen.

Auch wenn sie verdächtig aussieht.

AUFGABE 6: EXTERNES CSS
============================================================

Öffne jetzt:

style.css


Style dort zuerst den body.


Benutze:

font-family: Arial, Helvetica, sans-serif;

line-height: 1.5;


Danach kümmern wir uns um:

.tier


Jedes Tier soll einen Rahmen bekommen:

border: 2px solid black;


Außerdem soll jedes Tier bekommen:

padding: 10px;

margin: 10px 0;


Speichern.

Webseite anschauen.


============================================================
KURZE DENKPAUSE
============================================================

Schau dir deine Tier-Boxen an.


Was macht:

border?


Was macht:

padding?


Was macht:

margin?


Versuche es mit eigenen Worten zu erklären.


TIPP:


padding

ist der Abstand INNERHALB eines Elements.


margin

ist der Abstand AUSSERHALB eines Elements.


Stell dir eine Transportbox vor:

Das Tier sitzt innen.

padding wäre der Platz zwischen dem Tier
und dem Rand der Box.

margin wäre der Abstand
zwischen dieser Box und der nächsten Box.

AUFGABE 11: DER CSS-TEST
============================================================

Jetzt testen wir,
welche CSS-Regel gewinnt.


Erstelle einen neuen Absatz:


<p class="test">
Welche Farbe bekomme ich?
</p>


Schreibe in deine EXTERNE style.css:


.test {
    color: blue;
}


Speichern.


Welche Farbe hat der Text?


____________________________


Jetzt schreibst du in dein INTERNES CSS:


.test {
    color: green;
}


Speichern.


Welche Farbe hat der Text jetzt?


____________________________


Zum Schluss bekommt der Absatz Inline CSS:


style="color: purple;"


Welche Farbe hat der Text jetzt?


____________________________


Was fällt dir auf?


Für diese Übung kannst du dir merken:


Inline CSS

hat normalerweise eine sehr hohe Priorität.


Wenn zwei gleich starke Regeln vorhanden sind,
kann auch die Reihenfolge wichtig sein.


Das Thema dahinter heißt:

CSS Cascade


Das schauen wir uns später genauer an.


Für heute reicht es zu wissen:

Mehrere CSS-Regeln können gleichzeitig
auf dasselbe Element wirken.


Ein bisschen wie drei Katzen,
die gleichzeitig denselben Karton wollen.
