CSS-Selektoren

Die Kunst, genau das richtige Element zu erwischen.

Selector Training Ground

CSS ohne Selektoren wäre wie Debugging ohne Fehlermeldung: Man weiß, dass etwas passieren soll, aber nicht wo.

  1. Level 1: Elementselektor

    Der Elementselektor wählt Elemente anhand ihres HTML-Tags aus.

  2. Level 2: Klassenselektor

    class="code"

    Eine Klasse kann von mehreren Elementen verwendet werden.

  3. Level 3: Der ID-Boss

    Eine ID sollte auf einer Seite eindeutig sein. Genau ein Element. Ein Boss. Keine Klone.

  4. Level 4: Attributselektor

    Manche Elemente verstecken ihre Informationen in Attributen. CSS findet sie trotzdem.

  5. Level 5: Universalmodus

    Ein Selektor, sie alle zu finden. Ein Sternchen, sie alle zu stylen.
