CSS Flexbox - Grundlagen

Flexbox ist dafür da, mehrere Elemente ordentlich nebeneinander oder untereinander anzuordnen und auszurichten.

1. Flexbox einschalten

Flexbox wird auf dem Eltern-Element aktiviert: display: flex. Die direkten Kinder werden zu "Flex-Items".

Item 1
Item 2
Item 3
                .flex-row{
                    display: flex;              -> Aktiviert das alle Items nebeneinander statt untereinander, stehen
                    border: 2px solid #eee;
                    padding: 8px;
                }

2. Richtungen: row VS column

Mit flex-direction bestimmst du die Ausrichtung: row = nebeneinander oder column = untereinander.

Item 1
Item 2
Item 3
Item 1
Item 2
Item 3
                .flex-row{
                    display: flex;          -> Aktiviert Flexbox      
                    flex-direction: row;    -> Items stehen nebeneinander
                }

                .flex-column{
                    display: flex;          -> Aktiviert Flexbox
                    flex-direction: column; -> Items stehen untereinander
                }

3. Abstände zwischen den Items: gap

gap macht gleichmäßige Abstände zwischen den Elementen (Items).

Item 1
Item 2
Item 3
                .gap{
                    gap: 12px;  -> gleichmäßige Abstände zw. den Elementen/ Items
                }
