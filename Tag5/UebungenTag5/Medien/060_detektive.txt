AUFGABE – DAS DETEKTIVBÜRO

Bearbeitungszeit: ca. 40 Minuten

THEMA:
HTML und CSS miteinander verbinden, Bilder, Videos und Sounds einfügen, verschiedene CSS-Größeneinheiten verwenden und ein neues CSS-Element kennenlernen.

==================================================
SZENARIO
========

In der Stadt häufen sich geheimnisvolle Fälle.

Verschwundene Gegenstände, rätselhafte Nachrichten und seltsame Beobachtungen beschäftigen die Bewohner.

Du arbeitest für das Detektivbüro „Spurensucher“ und sollst eine Webseite für das Büro erstellen.

Auf der Webseite sollen:

* das Detektivbüro vorgestellt werden
* aktuelle Fälle gezeigt werden
* Bilder eingebunden werden
* ein Sound eingebunden werden
* ein Video eingebunden werden
* verschiedene Bereiche gestaltet werden
* unterschiedliche CSS-Größeneinheiten verwendet werden

Am Ende soll deine Webseite wie eine geheimnisvolle Detektiv-Webseite aussehen.

==================================================

=============

Erstelle einen neuen Ordner:

detektivbuero

In diesem Ordner legst du folgende Dateien und Ordner an:

video

img

Speichere deine Sounddatei im Ordner:

Speichere dein Video im Ordner:

AUFGABE 1 – HTML-GRUNDGERÜST
============================

Erstelle die Datei:

index.html

Füge folgendes HTML-Grundgerüst ein:

<!DOCTYPE html>

<html lang="de">

<head>

```
<meta charset="UTF-8">

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<title>Detektivbüro Spurensucher</title>

<link rel="stylesheet" href="style.css">
```

</head>

<body>

```
<header>

    <h1>Detektivbüro Spurensucher</h1>

    <p>
        Kein Rätsel bleibt ungelöst.
    </p>

</header>


<main>

    <section>

        <h2>Willkommen im Detektivbüro</h2>

        <p>
            Unser Detektivbüro untersucht ungewöhnliche
            und geheimnisvolle Fälle.

            Wir suchen nach Hinweisen, befragen Zeugen
            und versuchen herauszufinden,
            was wirklich passiert ist.
        </p>

    </section>

</main>
```

</body>

</html>

Öffne die Datei anschließend im Browser.

Überprüfe:

Wird die Überschrift angezeigt?

Wird der Text angezeigt?

Wenn ja, kannst du weitermachen.

AUFGABE 2 – CSS-DATEI ERSTELLEN
===============================

Erstelle eine neue Datei:

style.css

Deine CSS-Datei wird mit folgender Zeile
mit der HTML-Datei verbunden:

<link rel="stylesheet" href="style.css">

Gestalte zuerst den gesamten <body>.

Füge in deine style.css ein:

body {
background-color: #1d1d1d;
color: #eeeeee;
font-family: Arial, sans-serif;
}

Du darfst die Farben später selbst verändern.

AUFGABE 14 – NEUES CSS-ELEMENT: box-shadow
==========================================

Jetzt lernst du eine neue CSS-Eigenschaft kennen:

box-shadow

Mit box-shadow kannst du einem Element
einen Schatten geben.

Beispiel:

section {
box-shadow: 0 4px 12px black;
}

Die Werte bedeuten:

0

= Verschiebung nach links oder rechts

4px

= Verschiebung nach oben oder unten

12px

= Unschärfe des Schattens

black

= Farbe des Schattens

DEINE AUFGABE:

Füge bei mindestens zwei Elementen
einen Schatten ein.

Zum Beispiel:

header

section

.fall

.buerobild

.beweisbild

video

AUFGABE 16 – DIE GRÖSSENEINHEITEN
=================================

Du hast jetzt verschiedene Größeneinheiten verwendet.

---

px

---

Beispiel:

border: 2px solid #b28b43;

px bedeutet:

Pixel

px ist eine feste Größe.

Gut geeignet für:

* Rahmen
* kleine Details
* kleine feste Größen

---

%

---

Beispiel:

width: 80%;

% orientiert sich meistens am verfügbaren Platz
beziehungsweise am Elternelement.

Gut geeignet für:

* flexible Breiten
* Bilder
* Audio
* Videos

---

rem

---

Beispiel:

padding: 2rem;

rem orientiert sich an der Schriftgröße
des <html>-Elements.

Gut geeignet für:

* Abstände
* Schriftgrößen
* margin
* padding

---

em

---

Beispiel:

font-size: 1.4em;

em orientiert sich an der Schriftgröße
des jeweiligen Elements beziehungsweise
seines Kontextes.

Gut geeignet für:

* relative Schriftgrößen
* Elemente, deren Größe von ihrer Umgebung
  abhängig sein soll

---

vw

---

Beispiel:

width: 40vw;

vw bedeutet:

Viewport Width

1vw entspricht:

1 % der Breite des Browserfensters.

Gut geeignet für:

* Elemente, die sich an der Fensterbreite orientieren

---

vh

---

Beispiel:

min-height: 25vh;

vh bedeutet:

Viewport Height

1vh entspricht:

1 % der Höhe des Browserfensters.

Gut geeignet für:

* große Bereiche
* Header
* Startbereiche
* Elemente, die sich an der Fensterhöhe orientieren

BONUSAUFGABE – :hover
=====================

Du bist früher fertig?

Finde selbst heraus, was

:hover

in CSS macht.

Teste zum Beispiel:

.fall:hover {
transform: scale(1.02);
}

Oder:

.beweisbild:hover {
border: 5px solid gold;
}

Beobachte, was passiert,
wenn du mit der Maus über das Element fährst.

BONUS 2:

Versuche zusätzlich:

cursor: pointer;

Beispiel:

.beweisbild:hover {
cursor: pointer;
}
