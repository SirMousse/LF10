AUFGABE – EINE REISE DURCH MITTELERDE

Bearbeitungszeit: ca. 40 Minuten

THEMA:
HTML und CSS miteinander verbinden, Bilder, Videos und Sounds einfügen, verschiedene CSS-Größeneinheiten verwenden und ein neues CSS-Element kennenlernen.

==================================================
SZENARIO
========

Eine gefährliche Reise durch Mittelerde beginnt.

Auf deiner Webseite soll eine kleine Abenteuerseite entstehen, die sich thematisch an „Der Herr der Ringe“ orientiert.

Die Besucher sollen etwas über die Reise, verschiedene Orte und Gefahren erfahren.

Auf der Webseite sollen:

* Mittelerde vorgestellt werden
* Bilder eingebunden werden
* ein Sound eingebunden werden
* ein Video eingebunden werden
* verschiedene Bereiche gestaltet werden
* unterschiedliche CSS-Größeneinheiten verwendet werden

Am Ende soll deine Webseite wie eine düstere Fantasy-Abenteuerseite wirken.

==================================================

=============

Erstelle einen neuen Ordner:

mittelerde

In diesem Ordner legst du folgende Dateien und Ordner an:

img
audio
video

Speichere deine Bilder im Ordner:

img

Speichere deine Sounddatei im Ordner:

audio

Speichere dein Video im Ordner:

==================================================
AUFGABE 1 – HTML-GRUNDGERÜST
============================

Erstelle die Datei:

index.html

Füge folgendes HTML-Grundgerüst ein:

<!DOCTYPE html>

<html lang="de">

<head>
    <meta charset="UTF-8">

```
<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<title>Eine Reise durch Mittelerde</title>

<link rel="stylesheet" href="style.css">
```

</head>

<body>

```
<header>

    <h1>Eine Reise durch Mittelerde</h1>

    <p>
        Ein Ring. Eine Reise. Ein großes Abenteuer.
    </p>

</header>


<main>

    <section>

        <h2>Willkommen in Mittelerde</h2>

        <p>
            Mittelerde ist eine Welt voller geheimnisvoller
            Wälder, großer Berge und alter Königreiche.

            Auf einer Reise durch dieses Land warten
            Freunde, Feinde und viele Gefahren.
        </p>

    </section>


</main>
```

</body>

</html>

Öffne die Datei anschließend im Browser und überprüfe,
ob Überschrift und Text angezeigt werden.

==================================================
AUFGABE 2 – CSS-DATEI ERSTELLEN
===============================

Erstelle eine neue Datei:

style.css

Die CSS-Datei wird durch folgende Zeile
mit deiner HTML-Datei verbunden:

<link rel="stylesheet" href="style.css">

Gestalte zuerst den gesamten <body>.

Füge in deine style.css ein:

body {
background-color: #1c2118;
color: #f2ead3;
font-family: Georgia, serif;
}

Du darfst die Farben später selbst verändern.

==================================================
AUFGABE 3 – DEN HEADER GESTALTEN
================================

Gestalte den Kopfbereich deiner Webseite.

Ergänze deine CSS-Datei:

header {
background-color: #34422b;
text-align: center;
padding: 2rem;
}

Gestalte zusätzlich die Hauptüberschrift:

font-size: 2.5rem;
letter-spacing: 2px;
}

WICHTIG:

Für die Schriftgröße verwendest du:

* Schriftgrößen
* Abstände
* padding
* margin

AUFGABE 9 – EINEN SOUND EINFÜGEN
================================

Jetzt soll deine Mittelerde-Webseite
eine Audiodatei enthalten.

Suche oder verwende eine passende Audiodatei.

Zum Beispiel:

* Fantasy-Musik
* Wind
* Waldgeräusche
* Schritte
* Kampfgeräusche
* mystische Musik

Speichere die Datei im Ordner:

audio

Benenne sie zum Beispiel:

reise.mp3

Füge einen neuen Bereich ein:

<section>

```
<h2>Klänge von Mittelerde</h2>

<p>
    Höre dir die Geräusche an,
    die eine Reise durch Mittelerde begleiten könnten.
</p>

<audio controls>

    <source
        src="./audio/reise.mp3"
        type="audio/mpeg">

    Dein Browser unterstützt dieses Audio nicht.

</audio>
```

</section>

Das Attribut:

controls

sorgt dafür, dass Play, Pause und Lautstärke angezeigt werden.

AUFGABE 14 – NEUES CSS-ELEMENT: box-shadow
==========================================

Jetzt lernst du eine neue CSS-Eigenschaft kennen:

box-shadow

Damit kannst du einem Element einen Schatten geben.

Beispiel:

section {
box-shadow: 0 4px 12px black;
}

Bedeutung:

0

= Verschiebung nach links oder rechts

4px

= Verschiebung nach oben oder unten

12px

= Stärke der Unschärfe

black

= Farbe des Schattens

DEINE AUFGABE:

Füge bei mindestens zwei Elementen
einen Schatten ein.

Zum Beispiel:

header

section

.mittelerdebild

.reise

video

AUFGABE 16 – DIE GRÖSSENEINHEITEN
=================================

Du hast jetzt folgende Einheiten verwendet:

px

Beispiel:

border: 2px solid #b99746;

px ist eine feste Größe.

Gut geeignet für:

* Rahmen
* kleine Details
* kleine feste Werte

---

%

Beispiel:

width: 80%;

% orientiert sich am verfügbaren Platz
beziehungsweise am Elternelement.

Gut geeignet für:

* flexible Breiten
* Bilder
* Audio
* Videos

---

rem

Beispiel:

padding: 2rem;

rem orientiert sich an der Schriftgröße
des <html>-Elements.

Gut geeignet für:

* Abstände
* Schriftgrößen
* margin
* padding

---

em

Beispiel:

font-size: 1.4em;

em orientiert sich an der Schriftgröße
des jeweiligen Elements oder seines Kontextes.

---

vw

Beispiel:

width: 40vw;

vw orientiert sich an der Breite
des Browserfensters.

---

vh

Beispiel:

min-height: 25vh;

vh orientiert sich an der Höhe
des Browserfensters.

BONUSAUFGABE – :hover
=====================

Du bist früher fertig?

Finde heraus, was

:hover

macht.

Teste zum Beispiel:

transform: scale(1.02);
}

Oder:

.reisebild:hover {
border: 5px solid gold;
}

Beobachte, was passiert,
wenn du mit der Maus über das Element fährst.
