Mission 4 – Das Passwort-Terminal

HTML

CSS
CSS steht für Cascading Style Sheets. Damit wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Schriftarten, Größen und Abstände.
URL
URL steht für Uniform Resource Locator. Eine URL ist die Adresse einer Ressource im Internet, zum Beispiel einer Webseite, Datei oder eines Bildes.

Bonus-Mission – Die Cyber-Begriffe

Firewall
Eine Firewall überwacht und filtert Netzwerkverkehr. Sie kann dabei helfen, unerlaubte Verbindungen zu blockieren.
Phishing
Phishing ist eine Methode, bei der Angreifer versuchen, Menschen mit gefälschten Nachrichten oder Webseiten zur Herausgabe sensibler Daten zu bringen.
Malware
Malware ist schädliche Software, die zum Beispiel Daten stehlen, Systeme beschädigen oder unerwünschte Aktionen ausführen kann.
Verschlüsselung
Verschlüsselung wandelt Daten so um, dass sie ohne den passenden Schlüssel nicht einfach gelesen werden können.

Zusatzfrage

Firewall und Verschlüsselung sind Schutzmaßnahmen. Phishing ist eine Angriffsmethode und Malware ist schädliche Software, die als Bedrohung eingesetzt werden kann.
