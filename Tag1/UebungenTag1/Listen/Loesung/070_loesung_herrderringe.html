Quest 4 – Das Rätsel von Bruchtal

HTML
HTML steht für HyperText Markup Language. Damit wird die Struktur und der Inhalt einer Webseite aufgebaut, zum Beispiel Überschriften, Texte, Bilder und Listen.
CSS
CSS steht für Cascading Style Sheets. Damit wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Schriftarten, Größen und Abstände.
URL
URL steht für Uniform Resource Locator. Eine URL ist die Adresse einer Ressource im Internet, zum Beispiel einer Webseite, Datei oder eines Bildes.

Die letzte Prüfung

  • Eine <ol> wurde verwendet.
  • Eine <ul> wurde verwendet.
  • <dl>, <dt> und <dd> wurden verwendet.
  • Mindestens eine Liste wurde korrekt verschachtelt.
  • Die Attribute start, reversed und type wurden verwendet.
  • Eigene Inhalte wurden ergänzt.
  • Die HTML-Datei funktioniert im Browser.
