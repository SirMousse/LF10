Quest 4 – Das Rätsel der alten Tür

HTML
HTML steht für HyperText Markup Language. Damit wird die Struktur und der Inhalt einer Webseite aufgebaut, zum Beispiel Texte, Überschriften, Bilder und Listen.
CSS
CSS steht für Cascading Style Sheets. Damit wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Abstände, Größen und Schriftarten.
URL
URL steht für Uniform Resource Locator. Eine URL ist die Adresse einer Ressource im Internet, zum Beispiel einer Webseite, Datei oder eines Bildes.
