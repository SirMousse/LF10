Kapitel 1: Der verschwundene Quellcode

Quest 1 – Der Weg durch Hyrule

  1. Dorf verlassen
  2. Verlorenen Wald durchqueren
  3. Kakariko erreichen
  4. Todesberg überqueren
  5. Schloss von Hyrule betreten
  6. Geheime Kammer finden

Hier wird eine geordnete Liste verwendet, weil die Stationen in einer festen Reihenfolge besucht werden müssen. Mit dem Attribut start="5" beginnt die Nummerierung bei 5.

Quest 4 – Das Rätsel der Weisheit

HTML
HTML steht für HyperText Markup Language. Damit wird die Struktur und der Inhalt einer Webseite aufgebaut, zum Beispiel Überschriften, Texte, Bilder und Listen.
CSS
CSS steht für Cascading Style Sheets. Damit wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Abstände, Schriftarten und Größen.
URL
URL steht für Uniform Resource Locator. Eine URL ist die Adresse einer Ressource im Internet, zum Beispiel einer Webseite oder eines Bildes.

Bonus-Quest – Das Hyrule-Lexikon

Triforce
Das Triforce ist ein mächtiges Relikt aus drei Teilen. Sie stehen für Mut, Weisheit und Kraft.
Master-Schwert
Das Master-Schwert ist Links legendäre Waffe. Es wird besonders im Kampf gegen das Böse eingesetzt.
Hyrule
Hyrule ist das Königreich, in dem viele Abenteuer der Zelda-Reihe stattfinden.
Ganondorf
Ganondorf ist einer der bekanntesten Gegenspieler der Zelda-Reihe und besitzt große Macht.
Link
Link ist der Held vieler Zelda-Spiele. Er kämpft meistens dafür, Hyrule und seine Bewohner zu retten.

Die letzte Prüfung

  • Eine <ol> wurde verwendet.

  • <dl>, <dt> und <dd> wurden verwendet.
  • Listen wurden korrekt verschachtelt.
  • Die Attribute start und reversed wurden verwendet.
  • Eigene Inhalte wurden ergänzt.
  • Der HTML-Code kann im Browser ausgeführt werden.
