Kapitel 1: Ein verdächtig einfacher Auftrag

Fall 1 – Der Ablauf des Verbrechens

  1. Gebäude wird geöffnet
  2. Mitarbeiter betreten das Büro
  3. Strom fällt kurzzeitig aus
  4. Eine unbekannte Person betritt den Archivraum
  5. Die Datei verschwindet
  6. Alarm wird ausgelöst

Hier wird eine geordnete Liste verwendet, weil die Reihenfolge der Ereignisse wichtig ist. Mit start="4" beginnt die Nummerierung bei 4.

Fall 4 – Die verschlüsselte Nachricht

HTML
HTML steht für HyperText Markup Language. Damit wird die Struktur und der Inhalt einer Webseite aufgebaut, zum Beispiel Texte, Überschriften, Bilder und Listen.
CSS
CSS steht für Cascading Style Sheets. Damit wird das Aussehen einer Webseite gestaltet, zum Beispiel Farben, Schriftarten, Abstände und Größen.
URL
URL steht für Uniform Resource Locator. Eine URL ist die Adresse einer Ressource im Internet, zum Beispiel einer Webseite oder eines Bildes.

Fall 5 – Die Verdächtigen

  1. Professor Pixel

    Hinweis: Seine Zugangskarte wurde im Archiv gefunden.

  2. Frau Byte

    Hinweis: Sie war während des Stromausfalls im Gebäude.

  3. Herr Null

    Hinweis: Auf seinem Computer wurde nach der verschwundenen Datei gesucht.

  4. Dr. Cookie

    Hinweis: Seine Fingerabdrücke wurden am Archivcomputer entdeckt.

  5. Alex Admin

    Hinweis: Er besitzt Administratorrechte für alle Computer im Gebäude.

Mit dem Attribut reversed wird die Nummerierung der geordneten Liste rückwärts angezeigt.

Bonus-Fall – Die geheime Akte

Fingerabdruck
Ein Fingerabdruck ist ein individuelles Muster auf den Fingern, das dabei helfen kann, eine Person zu identifizieren.
Alibi
Ein Alibi soll zeigen, dass sich eine Person zur Tatzeit an einem anderen Ort befunden hat.
Motiv
Ein Motiv ist ein möglicher Grund dafür, warum jemand eine Tat begangen haben könnte.
Indiz
Ein Indiz ist ein Hinweis, der auf einen bestimmten Ablauf oder eine bestimmte Person hindeuten kann, aber allein noch kein sicherer Beweis ist.
