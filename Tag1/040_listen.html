Listen in HTML

In diesem Abschnitt kann ich alles über verschiedene Listen nachlesen. HTML kennt:
<ol> (sortierten Listen), <ul> (unsortierten Listen) und <dl> (beschreibende Listen).

1. Wann nutzen wir welche Liste?

  • <ol>: Wenn die Reihenfolge wichtig ist (Bsp.: Ranglisten, Rezepte, Anleitung)
  • <ul>: Wenn die Reihenfolge egal ist (Bsp.: Stichpunkten, Einkaufslisten, To-Do Listen)
  • <dl>: Für Begriffe mit Erklärungen (Bsp.: Glossar, FAQ, Wörterbuch)

2. Sortierte Liste (<ol>)

Eine sortierte Liste nummiert die Einträge automatisch.

Beispiel (früh aufstehen):

  1. Augen öffnen
  2. Aufrichten
  3. Uns aus dem Bett bewegen

Wichtige Attribute

  • type: 1, A, a, I, i
  • start: Startwert festlegen
  • reversed: Nummerierung umdrehen

Beispiel:

  1. Erster Punkt
  2. Zweite Punkt
  3. Dritte Punkt

3. Unsortierte Liste (<ul>)

Eine unsortierte Liste stellt Aufzählungen dar, bei der die Reihenfolge egal ist.

Beispiel (Haustiere):

  • Hund
  • Katze
  • Kaninchen

Wichtige Attribute

  • type: circle, square

Beispiel:

  • Bär
  • Puma
  • Hai

4. Beschreibende Listen (<dl>)

Eine beschreibende Liste besteht aus: <dt> (Begriff) und <dd> (Beschreibung).

Beispiel:

HTML
Auszeichnungssprache zur Strukturierung von Webseiten.

CSS
Sprache für das Design und Layout einer Webseite.

Mehrere Beschreibungen zu einem Begriff

Dackel
Hunderasse
Gilt als intelligent, lernfähig und stur.

5. Verschachtelte Liste

Listen können in anderen Listen eingebettet werden (Bsp.: für Menü oder Kategorien).

Beispiel:

  • Produkt
    • Handys
      • Android
      • iOS
    • Laptop

Beispiel Rucksack:

  1. Rucksack
    • Fach 1
      • Schere
      • Stifte
    • Fach 2
      1. Wasserflasche
      2. Tascherechner

Anleitung: Verschachtelte Listen in HTML

  1. Erstellt zuerst eine normale Liste mit <ul> oder <ol>.
  2. Füge mit <li> einen Listeneintrag hinzu.
  3. Schreibe einen Text für den Haupteintrag in das <li>-Element.
  4. Erstelle innerhalb dieses <li>-Elements eine neue Liste mit <ul> oder <ol>.
  5. Füge die Unterpunkte mit weiteren <li>-Elements ein.
  6. Schließe zuerst die Unterliste und danach den Haupteintarg mit <li>.
