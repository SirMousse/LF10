SQL-ABENTEUER: DIE DATENBANK VON MITTELERDE
============================================

Willkommen, Datenbank-Gefährte!

Du bist neuer Archivhüter in Bruchtal.
Deine Aufgabe ist es, mit SQL Ordnung in das Archiv der Gefährten von Mittelerde zu bringen.

QUEST 1 - DAS ARCHIV VON BRUCHTAL
---------------------------------

Zeige alle Gefährten aus dem Archiv an.

SQL-Wissen:
Mit SELECT wählst du Daten aus einer Tabelle aus.

Beispiel:

    SELECT *
    FROM gefaehrten;

Das * bedeutet: Zeige alle Spalten an.


QUEST 2 - ELROND SUCHT ERFAHRENE GEFÄHRTEN
-------------------------------------------

Zeige alle Gefährten, die mindestens Level 7 erreicht haben.

Versuche zuerst selbst eine Abfrage zu schreiben.

Hinweis:

    WHERE level >= 7

SQL-Wissen:
Mit WHERE kannst du Datensätze filtern.

Wichtige Vergleichsoperatoren:

    =   gleich
    >   größer als
    <   kleiner als
    >=  größer oder gleich
    <=  kleiner oder gleich
    !=  ungleich


QUEST 3 - WER IST AM STÄRKSTEN?
-------------------------------

Zeige nur die Spalten:

    name
    volk
    staerke

Sortiere die Gefährten nach ihrer Stärke.

Der stärkste Gefährte soll ganz oben stehen.

SQL-Wissen:

    ORDER BY staerke DESC

DESC bedeutet "descending", also absteigend.
ASC bedeutet "ascending", also aufsteigend.


QUEST 4 - DIE GEMEINSCHAFT BRAUCHT AKTIVE HELDEN
-------------------------------------------------

Zeige alle Gefährten, die:

    - den Status "aktiv" haben
    - mindestens Level 7 sind

SQL-Wissen:
Mehrere Bedingungen kannst du mit AND verbinden.

Beispiel:

    WHERE status = 'aktiv'
    AND level >= 7;

Mit OR müsste dagegen nur eine der Bedingungen erfüllt sein.


QUEST 5 - SAM WIRD STÄRKER
--------------------------

Sam beweist auf der Reise großen Mut.

Seine Stärke steigt von 80 auf 100.

Schreibe eine SQL-Abfrage, die Sams Stärke verändert.

SQL-Wissen:
Mit UPDATE kannst du bestehende Daten verändern.

Beispiel:

    UPDATE gefaehrten
    SET staerke = 100
    WHERE name = 'Sam';

Wichtig:
Ein UPDATE ohne WHERE kann alle Datensätze der Tabelle verändern.


BOSS-QUEST - DIE SCHLACHT UM MITTELERDE
---------------------------------------

Saurons Armeen bedrohen Mittelerde.

Nur besonders erfahrene und starke Gefährten dürfen an der entscheidenden Schlacht teilnehmen.

Gesucht werden Gefährten, die:

    - mindestens Level 7 sind
    - den Status "aktiv" haben
    - mindestens 150 Stärke besitzen

Gib nur folgende Spalten aus:

    name
    volk
    level
    staerke

Sortiere die Gefährten anschließend vom höchsten zum niedrigsten Level.

Schreibe die vollständige SQL-Abfrage selbst.

Du wirst wahrscheinlich folgende SQL-Befehle benötigen:

    SELECT
    FROM
    WHERE
    AND
    ORDER BY
    DESC


BONUS-QUEST - STATISTIK FÜR ELROND
----------------------------------

Elrond möchte wissen:

Wie viel Stärke besitzen alle Gefährten zusammen?

Dafür gibt es in SQL sogenannte Aggregatfunktionen.

Beispiel:

    SUM(staerke)

Weitere nützliche Funktionen:

    COUNT()
    AVG()
    MIN()
    MAX()

Damit kannst du Datensätze zählen, Durchschnittswerte berechnen oder den kleinsten und größten Wert finden.


GELERNTES SQL-WISSEN
--------------------

Nach Abschluss der Aufgaben kennst du unter anderem:

    SELECT
    FROM
    WHERE
    AND
    OR
    ORDER BY
    UPDATE
    SUM()

Damit kannst du Daten anzeigen, filtern, sortieren, verändern und auswerten.
